# 📊 Students AI Usage Analysis

This Data Science project explores the impact of AI tools on students' academic performance, study habits, and screen time. The project includes data cleaning, exploratory data analysis (EDA), data visualization, and a simple machine learning model for grade prediction.

## 🚀 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📌 Project Tasks
- Dataset Understanding
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Predictive Modeling

## 📈 Key Findings
- AI usage showed a positive impact on student grades.
- Study hours were positively related to academic performance.
- Visualizations helped identify important trends and patterns.
